P001 · LC1 两数之和 简单

解法: 一次遍历 + 哈希表（值→下标）

💡 别回头找搭档：把"我还需要谁"记进哈希表，让答案自己来撞上门——空间换时间。

class Solution:
    def twoSum(self, nums, target):
        seen = {}                     # 值 -> 下标
        for i, x in enumerate(nums):
            y = target - x            # 需要的另一半
            if y in seen:             # 之前出现过吗?
                return [seen[y], i]
            seen[x] = i               # 登记自己

时间 O(n)　·　空间 O(n)（哈希表最多存 n 个数）

P002 · LC49 字母异位词分组 中等

解法: 排序作 key + 哈希分组

💡 给每个词发一张“排序后的身份证”：异位词身份证必然相同——哈希表按身份证分堆，一组不漏。

class Solution:
    def groupAnagrams(self, strs):
        groups = {}                     # 钥匙(排序后的词) -> 组员名单
        for s in strs:                  # 逐个处理单词
            key = ''.join(sorted(s))    # 异位词排序后长得一模一样
            if key not in groups:       # 第一次见到这把钥匙?
                groups[key] = []        # 先开一个新组
            groups[key].append(s)       # 飞进自己的组
        return list(groups.values())    # 每串名单就是一组答案

时间 O(n·k log k)（n 个单词，词长 k）　·　空间 O(n·k)（哈希表存全部单词）

P003 · LC128 最长连续序列 中等

解法: 哈希集合，只从序列起点向右数

💡 连续段必有“没人差它一”的头：只让头向右数到底，其余数原地待命——每个数最多被摸两次，O(n) 拿下。

class Solution:
    def longestConsecutive(self, nums):
        numSet = set(nums)              # 全部丢进哈希集合, 查询 O(1)
        best = 0                        # 目前最长的连续长度
        for x in numSet:                # 每个数都试着当一次起点
            if x - 1 in numSet:         # x-1 也在集合里?
                continue                # 是 -> x 不是头, 让位
            length = 1                  # x 就是头, 链条至少长 1
            while x + length in numSet: # 右邻 x+length 也在?
                length += 1             # 在! 链条再加一节
            best = max(best, length)    # 这段数完, 刷新纪录
        return best

时间 O(n)（每个数最多被查常数次）　·　空间 O(n)（哈希集合）

P004 · LC283 移动零 简单

解法: 快慢指针，非零数前移

💡 fast 只管找非零数，找到就换到 slow 手里；slow 是非零区的墙、只进不退——一遍扫完，0 全被挤到右边。

class Solution:
    def moveZeroes(self, nums):
        slow = 0                        # 墙: slow 左边全是排好的非零数
        for fast in range(len(nums)):   # fast 逐格探路
            if nums[fast] != 0:         # 捡到非零数?
                nums[slow], nums[fast] = nums[fast], nums[slow]  # 换到墙外
                slow += 1               # 非零区向右扩一格

时间 O(n)（fast 每格只看一次）　·　空间 O(1)（原地双指针）

P005 · LC11 盛最多水的容器 中等

解法: 两端夹逼，每次移动矮的一侧

💡 水由短板封顶：留住高板、挪走矮板，才可能遇到更高的搭档——每次牺牲一点宽度换高度的可能，一趟 O(n) 夹逼出答案。

class Solution:
    def maxArea(self, height):
        l, r = 0, len(height) - 1       # 左右两根板, 从最两端出发
        best = 0                        # 目前最大的装水量
        while l < r:                    # 两板没碰头, 就继续试
            area = min(height[l], height[r]) * (r - l)  # 水量 = 矮板高 × 宽
            best = max(best, area)      # 刷新纪录
            if height[l] < height[r]:   # 左板更矮?
                l += 1                  # 挪走矮的左板, 保留高板
            else:
                r -= 1                  # 右板不比左板高, 挪走右板
        return best

时间 O(n)（每轮挪一根板，最多 n−1 轮）　·　空间 O(1)

P006 · LC15 三数之和 中等

解法: 排序 + 固定一个 + 左右双指针

💡 排序后固定 i，l、r 夹逼：和小 l 右移、和大 r 左移；命中后 i、l、r 三处各跳过重复值，一组不多、一组不少。

class Solution:
    def threeSum(self, nums):
        nums.sort()                     # 先排好队: 相同的数会挨在一起
        res = []
        for i in range(len(nums) - 2):  # 固定第一个数 nums[i]
            if i > 0 and nums[i] == nums[i - 1]:  # 去重①: 该基准刚用过
                continue
            l, r = i + 1, len(nums) - 1  # 左右指针从两端向中间夹逼
            while l < r:                # 没碰头就继续找
                s = nums[i] + nums[l] + nums[r]
                if s < 0:               # 和偏小 -> 左针右移
                    l += 1
                elif s > 0:             # 和偏大 -> 右针左移
                    r -= 1
                else:                   # 和正好为 0, 记录!
                    res.append([nums[i], nums[l], nums[r]])
                    while l < r and nums[l] == nums[l + 1]: l += 1  # 去重②: 跳过重复左数
                    while l < r and nums[r] == nums[r - 1]: r -= 1  # 去重③: 跳过重复右数
                    l += 1; r -= 1      # 双双内缩, 找下一组
        return res

时间 O(n²)（排序 + 一层双指针）　·　空间 O(log n)（排序递归栈，不算答案）

P007 · LC42 接雨水 困难

解法: 双指针 + 两侧最大值，水往矮处流

💡 水位由两侧最高墙中较矮的一堵决定：lm < rm 时第 l 格水位必是 lm（右边罩得住），放心结算再移动矮的一侧——一趟扫完，空间 O(1)。

class Solution:
    def trap(self, height):
        ans = 0
        l, r = 0, len(height) - 1      # 两个哨兵
        lm, rm = 0, 0                  # 两侧见过的最高墙
        while l < r:
            lm = max(lm, height[l])    # 刷新左半最高
            rm = max(rm, height[r])    # 刷新右半最高
            if lm < rm:                # 矮的一侧说了算
                ans += lm - height[l]  # 左端水位 = lm
                l += 1
            else:
                ans += rm - height[r]  # 右端水位 = rm
                r -= 1
        return ans

时间 O(n)（l、r 合起来各走一趟）　·　空间 O(1)（只用几个变量）

P008 · LC3 无重复字符的最长子串 中等

解法: 右针扩张 + 左针收缩，集合查重

💡 右手无脑扩张，左手只在撞车时收缩——窗口永远是"以 r 结尾的最长无重复子串"，每稳住一次量一遍，最长即答案。

class Solution:
    def lengthOfLongestSubstring(self, s):
        occ = set()                    # 窗口内的字符名单
        ans, l = 0, 0                  # 最长长度 与 左端
        for r, c in enumerate(s):      # 右手 r 一路向右捡
            while c in occ:            # 撞见重复 -> 左手收缩
                occ.remove(s[l])       # 把左端字符请出窗
                l += 1
            occ.add(c)                 # 新字符进窗
            ans = max(ans, r - l + 1)  # 量一量窗口长度
        return ans

时间 O(n)（l、r 各走一趟）　·　空间 O(|Σ|)（名单最多装字符集大小）

P009 · LC438 找到字符串中所有字母异位词 中等

解法: 定长窗口 + 计数差

💡 别每次重排再比较——用"计数差"记账：进窗补一笔、滑出退一笔，账本恰好全平（differ = 0）的瞬间，定长窗口就是 p 的异位词。

class Solution:
    def findAnagrams(self, s, p):
        m = len(p)
        cnt = {}                        # 计数差 = 窗口 - 需求 (负 = 还缺)
        for c in p:
            cnt[c] = cnt.get(c, 0) - 1  # 先把 p 的账记成欠着
        differ = len(cnt)               # 账没平的字符种类数
        ans = []
        for r, c in enumerate(s):
            cnt[c] = cnt.get(c, 0) + 1  # 右端进窗, 补一笔
            if cnt[c] == 0:
                differ -= 1             # 这笔刚好平了
            elif cnt[c] == 1:
                differ += 1             # 反倒多出来了
            if r >= m:                  # 窗口超长, 左端滑出
                d = s[r - m]
                cnt[d] -= 1
                if cnt[d] == 0:
                    differ -= 1
                elif cnt[d] == -1:
                    differ += 1
            if r >= m - 1 and differ == 0:
                ans.append(r - m + 1)   # 账全平 -> 命中一段异位词
        return ans

时间 O(|s| + |p|)　·　空间 O(|Σ|)（账本最多装出现过的字符种类）

P010 · LC560 和为 K 的子数组 中等

解法: 前缀和 + 哈希表

💡 子数组的和 = 两段前缀相减。在第 i 格查"前缀和等于 pre−k 的旧前缀有几个"，一个旧前缀对应一段答案——哈希账本把 O(n²) 压成 O(n)，还不怕负数。

class Solution:
    def subarraySum(self, nums, k):
        pre = 0                        # 当前前缀和
        cnt = {0: 1}                   # 账本: 前缀和 -> 出现次数
        ans = 0
        for x in nums:
            pre += x                   # 前缀和走到当前格
            ans += cnt.get(pre - k, 0) # 有几个旧前缀 = pre-k
            cnt[pre] = cnt.get(pre, 0) + 1  # 登记当前前缀(先查后记!)
        return ans

P011 · LC239 滑动窗口最大值 困难

解法: 单调递减队列

💡 队列里只留"还可能当最大"的下标：队尾小的被新元素碾掉，队头过期的请走——队头即窗口最大，进出队各一次，均摊 O(n)。

from collections import deque

class Solution:
    def maxSlidingWindow(self, nums, k):
        dq = deque()                   # 存下标, 值从队头到队尾递减
        ans = []
        for i, x in enumerate(nums):
            if dq and dq[0] <= i - k:  # 队头滑出窗口左界 -> 请走
                dq.popleft()
            while dq and nums[dq[-1]] <= x:
                dq.pop()               # 队尾比 x 小: 留着也没用
            dq.append(i)               # 新下标进队尾
            if i >= k - 1:
                ans.append(nums[dq[0]])  # 队头 = 当前窗口最大值
        return ans

时间 O(n)（每个下标至多进队、出队各一次）　·　空间 O(k)（队列里最多 k 个下标）

📘 解法二 · 官方 · 优先队列(堆)

💡 堆里全都要：每个 (值取负, 下标) 都进大顶堆，堆顶过期就懒删除——堆顶永远是"值最大、最靠前"的合法候选。

# 解法二:力扣官方题解 方法一(优先队列)
import heapq

class Solution:
    def maxSlidingWindow(self, nums, k):
        h = []                         # 堆: 存 (值取负, 下标)
        ans = []
        for i, x in enumerate(nums):
            heapq.heappush(h, (-x, i))     # 新元素进堆, 值大者浮上堆顶
            while h[0][1] <= i - k:        # 堆顶下标滑出窗口 -> 懒删除
                heapq.heappop(h)
            if i >= k - 1:
                ans.append(-h[0][0])       # 堆顶 = 当前窗口最大值
        return ans

时间 O(n log n)（每个元素进出堆各一次，堆操作 O(log n)）　·　空间 O(n)（懒删除：过期元素可能滞留堆中）

P012 · LC76 最小覆盖子串 困难

解法: 滑动窗口 + 需求计数

💡 右指针无脑扩张捡货，凑齐就让左指针贪心收缩扔货——每次"刚好要不够"的瞬间量一下窗口长短，最短的那个就是答案。

class Solution:
    def minWindow(self, s, t):
        need = {}                        # 购物清单: t 里每种字符要几个
        for c in t:
            need[c] = need.get(c, 0) + 1
        win = {}                         # 购物车: 窗口里已有多少
        valid = 0                        # 已凑够需求的字符种类数
        best, l = '', 0                  # 最优答案 与 左端
        for r, c in enumerate(s):        # 阶段1: 右端一路扩张
            if c in need:
                win[c] = win.get(c, 0) + 1
                if win[c] == need[c]:    # 这种字符正好凑够
                    valid += 1
            while valid == len(need):    # 阶段2: 凑齐了 → 收缩
                if not best or r - l + 1 < len(best):
                    best = s[l:r+1]      # 记下更短的覆盖
                d = s[l]                 # 看看左端要扔谁
                if d in need:
                    if win[d] == need[d]:
                        valid -= 1       # 扔完后这种字符不够了
                    win[d] -= 1
                l += 1
        return best

时间 O(|s| + |t|)（两个指针各走一趟）　·　空间 O(|Σ|)（need/win 最多装字符集大小）

P013 · LC53 最大子数组和 中等

解法: DP：前缀为负就丢掉

💡 一路走一路攒和：cur 攒成负数就当场扔掉重开——"前面的累赘一个不带"；ans 只负责记下 cur 跑出的最高分。

class Solution:
    def maxSubArray(self, nums):
        ans = nums[0]               # 全局最大: 至少选一个数
        cur = 0                     # 以当前格结尾的连续和
        for x in nums:
            if cur < 0:             # 手上这段是负资产
                cur = 0             # 扔掉! 从 x 重新开始
            cur += x                # 把 x 接到当前段末尾
            if cur > ans:           # 出现更高的分
                ans = cur           # 刷新答案
        return ans

时间 O(n)（一遍扫描）　·　空间 O(1)（只留 cur、ans 两个变量）

📘 解法二 · 官方 · 分治

💡 一分为二：区间答案 = max(左内最优, 右内最优, 左尾接右头)——total/pre/suf/best 四个量恰好凑齐"拼接"所需的全部信息。

class Solution:
    def maxSubArray(self, nums):
        def get(l, r):                # 线段 [l,r] 的四元组
            if l == r:                # 叶子: 只剩一个数
                x = nums[l]
                return (x, x, x, x)   # (total, pre, suf, best)
            mid = (l + r) // 2
            a = get(l, mid)           # 左半的四元组
            b = get(mid + 1, r)       # 右半的四元组
            total = a[0] + b[0]                 # ① 总和: 两半全要
            pre = max(a[1], a[0] + b[1])        # ② 左端开头的最大前缀
            suf = max(b[2], b[0] + a[2])        # ③ 右端结尾的最大后缀
            best = max(a[3], b[3], a[2] + b[1]) # ④ 不跨 / 跨中线
            return (total, pre, suf, best)
        return get(0, len(nums) - 1)[3]

时间 O(n)（T(n) = 2T(n/2) + O(1)）　·　空间 O(log n)（递归栈深度）

P014 · LC56 合并区间 中等

解法: 按左端排序 + 依次合并

💡 排好序后，"要不要合并"只看一件小事：新来的左端 ≤ 结果末尾的右端。排序把所有可能的纠缠，都变成了"只看前一个"的线性扫描。

class Solution:
    def merge(self, intervals):
        intervals.sort(key=lambda x: x[0])   # 按左端点从小到大排
        merged = []                          # 结果: 已合并的区间们
        for it in intervals:
            if merged and it[0] <= merged[-1][1]:
                merged[-1][1] = max(merged[-1][1], it[1])  # 重叠→延伸末尾
            else:
                merged.append(list(it))      # 不重叠→新开一段
        return merged

时间 O(n log n)（排序为主，扫描 O(n)）　·　空间 O(n)（存结果）

P015 · LC189 轮转数组 中等

解法: 整体翻转 + 两段各自翻转

💡 旋转 = 整体翻转 + 前后各翻回来：[1,2,3,4,5,6,7] → [7,6,5,4,3,2,1] → [5,6,7|4,3,2,1] → [5,6,7|1,2,3,4]。

class Solution:
    def rotate(self, nums, k):
        n = len(nums)
        k %= n                       # k 可能比 n 大, 先取余
        def rev(i, j):               # 原地翻转 nums[i..j]
            while i < j:
                nums[i], nums[j] = nums[j], nums[i]
                i += 1; j -= 1
        rev(0, n - 1)                # 1) 整体翻转
        rev(0, k - 1)                # 2) 翻转前 k 个
        rev(k, n - 1)                # 3) 翻转后面一段

时间 O(n)（每个元素被交换常数次）　·　空间 O(1)（原地交换，不开新数组）

📘 解法二 · 官方 · 环状替换

💡 下标 i 的家在 (i+k)%n：拎着值沿环直送、把被覆盖的接着拎走；一圈走 n/gcd(n,k) 步回起点，共走 gcd(n,k) 圈才能铺满 n 格。

from math import gcd

class Solution:
    def rotate(self, nums, k):
        n = len(nums)
        k %= n                      # k 可能比 n 大, 先取余
        count = gcd(n, k)           # 圈数 = gcd(n, k)
        start = 0
        while count > 0:            # 一圈一圈归位
            cur = start
            prev = nums[start]      # 手里拎着待安放的值
            while True:             # 沿环跳跃
                nxt = (cur + k) % n # cur 的值最终要去的格子
                nums[nxt], prev = prev, nums[nxt]   # 安放, 并拎起被覆盖的值
                cur = nxt
                if cur == start:    # 绕回起点 → 这一圈闭合
                    break
            start += 1              # 下一个圈从 start+1 出发
            count -= 1

时间 O(n)（每个元素恰好被写入一次）　·　空间 O(1)（只借一个变量拎值）

P016 · LC238 除自身以外数组的乘积 中等

解法: 前缀乘 × 后缀乘

💡 答案 = 左边乘积 × 右边乘积。两遍扫描，第二遍用一个滚动变量顺手把右积乘上去——不用除法，也不用额外数组。

class Solution:
    def productExceptSelf(self, nums):
        n = len(nums)
        ans = [1] * n                # ans[i] 先存"左边全部乘积"
        for i in range(1, n):
            ans[i] = ans[i-1] * nums[i-1]
        right = 1                    # 右边全部乘积(不含 i)
        for i in range(n - 1, -1, -1):
            ans[i] *= right          # 左积 × 右积 = 答案
            right *= nums[i]         # 右积滚给下一格
        return ans

        return n + 1                   # 1~n 全齐, 答案是 n+1

P019 · LC54 螺旋矩阵 中等

解法: 四条边界逐层收缩

💡 四条边界像相框一圈圈往里拆：→ ↓ ← ↑ 各收一条边，每圈收完 top+1、bottom−1、left+1、right−1，边界交错就停。

class Solution:
    def spiralOrder(self, matrix):
        m, n = len(matrix), len(matrix[0])
        top, bottom = 0, m - 1
        left, right = 0, n - 1
        out = []
        while top <= bottom and left <= right:   # 还有没收的地盘
            for j in range(left, right + 1):     # → 顶行
                out.append(matrix[top][j])
            for i in range(top + 1, bottom + 1): # ↓ 右列
                out.append(matrix[i][right])
            if top < bottom:                     # 底行别和顶行重合
                for j in range(right - 1, left - 1, -1):   # ← 底行
                    out.append(matrix[bottom][j])
            if left < right:                     # 左列别和右列重合
                for i in range(bottom - 1, top, -1):       # ↑ 左列
                    out.append(matrix[i][left])
            top += 1; bottom -= 1; left += 1; right -= 1   # 内缩一圈
        return out

时间 O(mn)（每格收一次）　·　空间 O(1)（不算输出数组）

P022 · LC160 相交链表 简单

解法: 双指针互换轨道，相遇即交点

💡 让两个指针走同样的总路程：pA 走完 A 就去走 B，pB 走完 B 就去走 A——路程相同，要么在交点相遇，要么一起到 None。

class Solution:
    def getIntersectionNode(self, headA, headB):
        pA, pB = headA, headB
        while pA is not pB:
            pA = pA.next if pA else headB  # 走到头就换到另一条链
            pB = pB.next if pB else headA
        return pA                          # 相遇点就是交点(可能为 None)

时间 O(m+n)　·　空间 O(1)（只有两个指针）

📘 解法二 · 官方 · 哈希表

💡 官方最直白的思路：先把 A 链整条登记进哈希集合，B 链第一个查到的就是交点——用 O(m) 空间买"不用绕跑道"的简单。

class Solution:
    def getIntersectionNode(self, headA, headB):
        seen = set()                      # 哈希集合: 登记见过的每个节点
        pA = headA
        while pA:                         # 上半场: 扫 A 链, 逐个登记
            seen.add(pA)
            pA = pA.next
        pB = headB
        while pB:                         # 下半场: 扫 B 链, 逐个查表
            if pB in seen:                # 第一个查到的 = 交点
                return pB
            pB = pB.next
        return None                       # B 走完都没查到 → 不相交

时间 O(m+n)（两条链各扫一遍）　·　空间 O(m)（seen 最坏存下整条 A 链；先扫短的那条可降到 O(min(m,n))）

P023 · LC206 反转链表 简单

class Solution:
    def reverseList(self, head):
        prev, cur = None, head
        while cur:              # 还有节点没处理
            nxt = cur.next      # 先记住下一个
            cur.next = prev     # 箭头掉头, 指向 prev
            prev = cur          # prev 前进一格
            cur = nxt           # cur 前进一格
        return prev             # 新表头

P025 · LC141 环形链表 简单

解法: 快慢指针，追上即有环

💡 操场跑圈：跑得快的人每圈必从背后追上慢的人——快指针"套圈"撞上慢指针就有环；快指针能走到 None 就没环。

class Solution:
    def hasCycle(self, head):
        slow = fast = head          # 快慢指针同一地点出发
        while fast and fast.next:   # 快的能再走两步才继续
            slow = slow.next        # 慢的走 1 步
            fast = fast.next.next   # 快的走 2 步
            if slow is fast:        # 快的绕圈追上慢的
                return True         # 有环实锤
        return False                # 快的到头 = 无环

时间 O(n)　·　空间 O(1)

📘 解法二 · 官方 · 哈希集合

💡 有环 = 走着走着撞见老面孔：逐节点登记进哈希集合，重复即有环、走到 None 即无环——思路最直白，代价是 O(n) 空间。

class Solution:
    def hasCycle(self, head):
        visited = set()             # 集合: 登记见过的每个节点
        cur = head                  # 从头出发
        while cur:                  # 还没走出链尾就继续
            if cur in visited:      # 撞见老面孔 → 有环实锤
                return True
            visited.add(cur)        # 登记当前节点
            cur = cur.next          # 往前走一步
        return False                # 冲到 None 没重复 → 无环

        dic = {}                          # 原节点 → 新节点 的映射表
        cur = head
        while cur:                        # ① 第一遍: 复制各节点, 登记映射
            dic[cur] = Node(cur.val)
            cur = cur.next
        cur = head                        # 回到开头, 第二遍照表接线
        while cur:                        # ② 补 next 和 random
            dic[cur].next = dic.get(cur.next)
            dic[cur].random = dic.get(cur.random)
            cur = cur.next
        return dic[head]                  # ③ 新链表的头节点

P033 · LC148 排序链表 中等

解法: 快慢找中点 + 归并排序

💡 链表版归并排序：快慢指针找中点断开 → 两半各自排好 → merge 按大小逐个摘节点接起来。

class Solution:
    def sortList(self, head):
        if not head or not head.next:      # 递归出口: 空或单节点
            return head
        slow, fast = head, head.next       # fast 从第二个出发
        while fast and fast.next:          # 快慢指针找中点
            slow = slow.next
            fast = fast.next.next
        mid = slow.next                    # 中点后的第一格
        slow.next = None                   # 剪断, 左右两段独立
        l = self.sortList(head)            # 左半段排好序
        r = self.sortList(mid)             # 右半段排好序
        return self.merge(l, r)            # 归并成一条

    def merge(self, a, b):
        dummy = tail = ListNode(0)         # tail: 已合并部分的尾巴
        while a and b:
            if a.val <= b.val:             # 两边队头比一比
                tail.next = a; a = a.next  # 摘左边的
            else:
                tail.next = b; b = b.next  # 摘右边的
            tail = tail.next               # 尾巴后移
        tail.next = a if a else b          # 接上没比完的剩余段
        return dummy.next

时间 O(n log n)（每层归并 O(n)，共 log n 层）　·　空间 O(log n)（递归栈）

P034 · LC23 合并 K 个升序链表 困难

解法: 分治：两两合并（归并）

💡 分治两两合并：每轮把相邻两条升序链合成一条，条数减半，log K 轮后只剩一条——每次合并就是第 21 题的"摘队头"工序。

class Solution:
    def mergeKLists(self, lists):
        # LeetCode 传入 K 条升序链表, 这里用数组模拟节点
        def merge2(a, b):                  # 合并两条升序链
            i = j = 0; out = []
            while i < len(a) and j < len(b):
                if a[i] <= b[j]:           # 两队头比一比
                    out.append(a[i]); i += 1
                else:
                    out.append(b[j]); j += 1
            out += a[i:]; out += b[j:]     # 接上没比完的剩余段
            return out
        ls = [list(x) for x in lists]      # 每条链开一份拷贝
        while len(ls) > 1:                 # 两两合并, 条数每轮减半
            nxt = []
            for i in range(0, len(ls) - 1, 2):
                nxt.append(merge2(ls[i], ls[i + 1]))
            if len(ls) % 2:                # 落单的原样晋级
                nxt.append(ls[-1])
            ls = nxt
        return ls[0] if ls else []

P035 · LC94 二叉树的中序遍历 简单

解法: 递归：左 → 根 → 右

💡 中序 = 根在中间：先把左子树整个走完，回来记下自己，再去右子树。空位是递归的刹车。

class Solution:
    def inorderTraversal(self, root):
        res = []                       # 访问序列
        def dfs(node):                 # 中序: 左 → 根 → 右
            if not node:               # 空位: 什么都不记
                return
            dfs(node.left)             # 1. 先走完左子树
            res.append(node.val)       # 2. 回到根, 记下它
            dfs(node.right)            # 3. 再去右子树

        return res

📘 解法二 · 官方 · 迭代(显式栈)

💡 显式栈就是手动模拟的调用栈：cur 一路向左把祖先压栈，压到头弹栈访问、再转向右子树——递归转迭代的通用套路。

class Solution:
    def inorderTraversal(self, root):
        res = []
        stack = []                  # 显式栈: 手动模拟调用栈
        cur = root                  # 当前指针
        while cur or stack:         # 指针还有路走 或 栈里还有活

                stack.append(cur)   # 途经节点全部压栈
                cur = cur.left
            cur = stack.pop()       # 左边到底: 弹栈访问
            res.append(cur.val)     # 记入访问序列
            cur = cur.right         # 转向右子树
        return res

P038 · LC101 对称二叉树 简单

解法: 双指针递归：镜像位置互比

💡 对称 = 左右子树互为镜像：compare(a, b) 同时审一对镜像节点，外侧配外侧、内侧配内侧，两边都空就是出口 true。

class Solution:
    def isSymmetric(self, root):
        def compare(a, b):                 # 镜像位置上的一对节点
            if not a and not b:            # 两边都空: 对称
                return True
            if not a or not b:             # 只有一边空: 不对称
                return False
            if a.val != b.val:             # 值不同: 不对称
                return False
            out = compare(a.left, b.right)     # 外侧配外侧
            inside = compare(a.right, b.left)  # 内侧配内侧
            return out and inside
        return compare(root, root)         # 根和自己配对, 从顶比到底

class Solution:

P040 · LC102 二叉树的层序遍历 中等

解法: 队列 BFS，按层出队

💡 BFS 用队列排队：先定死本层人数 n，再只弹 n 个——弹一个记一个，孩子排在队尾，天然分成一层一层。

from collections import deque

class Solution:
    def levelOrder(self, root):
        if not root:                 # 空树直接返回
            return []
        q = deque([root])            # 队列: 还没处理的节点
        res = []
        while q:                     # 每一轮处理完整的一层
            n = len(q)               # 先定死本层人数
            row = []
            for _ in range(n):       # 只弹 n 个, 不会带出下一层
                node = q.popleft()   # 队首出队
                row.append(node.val) # 记进本层清单
                if node.left:        # 左孩子在队尾排队
                    q.append(node.left)
                if node.right:
                    q.append(node.right)
            res.append(row)          # 本层收工, 存入结果
        return res

时间 O(n)（每个节点入队、出队各一次）　·　空间 O(n)（队列最宽时约一层，最多 n/2 个）

📘 解法二 · 官方思路 · 手写队列(不用 deque)

💡 队列的本质是"头指针 + 追尾"：出队不必真删元素，head 右移一格即可——deque 的内部就是这么工作的。

class Solution:
    def levelOrder(self, root):
        if not root:                 # 空树直接返回
            return []
        queue = [root]               # 数组当队列: 节点依次排进来
        head = 0                     # 队头下标: 出队 = head+1
        res = []
        while head < len(queue):     # head 没追上队尾 = 队列非空
            n = len(queue) - head    # 本层人数 = 队尾 - 队头
            row = []
            for _ in range(n):       # 只出队 n 个
                node = queue[head]; head += 1   # 出队(不删元素)
                row.append(node.val)
                if node.left:        # 孩子排到数组尾
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            res.append(row)
        return res

时间 O(n)（每个节点进出队各一次）　·　空间 O(n)（数组保留所有节点）

P041 · LC108 将有序数组转换为二叉搜索树 简单

💡 中点当根、左右两段递归：有序数组的中点天生是平衡 BST 的根，切下去、递归下去，树就长出来了。

class Solution:
    def sortedArrayToBST(self, nums):
        def build(lo, hi):               # 负责 nums[lo..hi] 这一段
            if lo > hi:                  # 空段 -> 空树
                return None

        while out and out[-1] is None: out.pop()

from collections import deque

        return ans

P047 · LC437 路径总和 III 中等

解法: 前缀和 + 回溯（哈希计数）

💡 像"和为 K 的子数组"在树上重演：cur 是前缀和，cnt 记每个前缀出现过几次，cnt[cur − target] 就是到此节点收口、和为 target 的路径条数；回溯时注销。

class Solution:
    def pathSum(self, root, targetSum):
        cnt = {0: 1}                  # 前缀和 -> 出现次数(空前缀哨兵)
        ans = 0
        def go(node, cur):            # cur = 根一路走到 node 的和
            nonlocal ans
            if not node:
                return
            cur += node.val           # 走到 node, 更新前缀和
            ans += cnt.get(cur - targetSum, 0)   # 能凑出 target 的老前缀
            cnt[cur] = cnt.get(cur, 0) + 1       # 登记当前前缀
            go(node.left, cur)        # 左子树里继续找
            go(node.right, cur)       # 右子树里继续找
            cnt[cur] -= 1             # 回溯: 注销前缀(只留当前路)
        go(root, 0)
        return ans

时间 O(n)（每节点进出各一次，查表 O(1)）　·　空间 O(n)（哈希表 + 递归栈 O(h)）

📘 解法二 · 官方 · 双重 DFS

💡 暴力但直观：每个节点都当一次路径起点，从它向下 DFS 累加，cur 撞上 targetSum 就记一条——所有向下路径按"起点"分类，一条不漏。

class Solution:
    def pathSum(self, root, targetSum):
        ans = 0
        def rootSum(node, cur):          # 以 node 为起点向下探, 路径和累加到 cur
            nonlocal ans
            cur += node.val              # 把 node 加进路径和
            if cur == targetSum:         # 恰好凑出 → 脚下整条路都是合法路径
                ans += 1
            if node.left:                # 有左孩子就向左继续探
                rootSum(node.left, cur)
            if node.right:               # 有右孩子就向右继续探
                rootSum(node.right, cur)
        def dfs(node):                   # 外层: 枚举每个节点当一次路径起点
            rootSum(node, 0)             # ① 以 node 为起点, 从 0 开始探
            if node.left:                # ② 左子树里的节点也要当起点
                dfs(node.left)
            if node.right:               # ③ 右子树里的节点也要当起点
                dfs(node.right)
        if root:
            dfs(root)
        return ans

时间 O(n²)（n 个起点，每个都要向下扫一遍自己的子树）　·　空间 O(h)（只有递归栈，无哈希表）

P048 · LC236 二叉树的最近公共祖先 中等

解法: 递归：左右各找，两边都有即为答案

💡 每棵子树汇报"找到几个目标"；第一个从左右凑齐 2 个的节点，就是 p、q 的最近公共祖先。

class Solution:
    def lowestCommonAncestor(self, root, p, q):
        self.ans = None
        def dfs(node):                    # 返回: 这棵子树里找到几个目标
            if not node:
                return 0                  # 空位: 0 个
            cnt = dfs(node.left) + dfs(node.right)   # 左右各找到几个
            if node.val in (p, q):
                cnt += 1                  # 自己也是一个目标
            if cnt == 2 and self.ans is None:
                self.ans = node.val       # 第一个凑齐 2 个的 = 最近公共祖先
            return cnt
        dfs(root)
        return self.ans

时间 O(n)（每个节点访问一次）　·　空间 O(h)（递归栈，h 为树高）

📘 解法二 · 官方 · 父指针哈希

💡 先花 O(n) 记下全树的父指针，再把 p 的祖先链装进哈希集合；q 沿父链上溯，第一个出现在集合里的节点就是 LCA——两条链找第一个交点。

class Solution:
    def lowestCommonAncestor(self, root, p, q):
        parent = {root: None}            # 子节点 -> 父节点; 根没有父
        def dfs(node):                   # 一次 DFS 把父指针记录全
            if node.left:
                parent[node.left] = node # 记下父指针
                dfs(node.left)
            if node.right:
                parent[node.right] = node
                dfs(node.right)
        dfs(root)
        pn = qn = None                   # 页面传的是值, 先定位节点
        for nd in parent:
            if nd.val == p: pn = nd
            if nd.val == q: qn = nd
        if not (pn and qn):              # 树里没有 p 或 q → 无祖先可谈
            return None
        anc = set()                      # p 的祖先链(含 p 自己)
        while pn:
            anc.add(pn.val)              # 祖先逐个放进集合
            pn = parent[pn]              # 沿父链上溯一步
        while qn.val not in anc:         # q 沿父链上溯, 逐站查集合
            qn = parent[qn]              # 不在就往上走一步
        return qn.val                    # 第一个撞进集合的 = 最近公共祖先

时间 O(n)（一次 DFS 记父指针 + 两条链各上溯 O(h)）　·　空间 O(n)（父指针表 + 祖先集合）

P049 · LC124 二叉树中的最大路径和 困难

解法: 递归单边贡献，弯路在节点处更新

💡 每个节点给上面只带一条边：gain = max(左, 右) + 自己（负的砍成 0）；弯路 l+r+自己 只在当地结算进 ans。

class Solution:
    def maxPathSum(self, root):
        self.ans = float('-inf')
        def gain(node):                       # 单边最大贡献(负的砍成 0)
            if not node:
                return 0
            l = max(gain(node.left), 0)       # 左边贡献, 负的不要
            r = max(gain(node.right), 0)      # 右边贡献, 负的不要
            self.ans = max(self.ans, l + r + node.val)   # 弯路: 左+右+自己
            return max(l, r) + node.val       # 给上面用的: 只能选一边
        gain(root)
        return self.ans

时间 O(n)（每个节点访问一次）　·　空间 O(h)（递归栈，h 为树高）

P050 · LC200 岛屿数量 中等

解法: DFS 淹岛：遇 1 就沉没整座岛

💡 扫到 1 就 ans+1 并把整座岛 DFS 淹成 0：每个格子要么被数一次，要么被淹一次，绝不重复。

class Solution:
    def numIslands(self, grid):
        m, n = len(grid), len(grid[0])
        def sink(i, j):                  # 把 (i,j) 连着的陆地全淹成 0
            if 0 <= i < m and 0 <= j < n and grid[i][j] == 1:
                grid[i][j] = 0           # 淹掉这一格
                sink(i+1, j)             # 向四个方向继续淹
                sink(i-1, j)
                sink(i, j+1)
                sink(i, j-1)
        ans = 0
        for i in range(m):               # 逐格扫描
            for j in range(n):
                if grid[i][j] == 1:      # 踩到陆地 = 发现新岛
                    ans += 1             # 岛数 +1
                    sink(i, j)           # 整座岛淹掉, 防止重复计数
        return ans

时间 O(mn)（每格最多访问常数次）　·　空间 O(mn)（递归栈最坏情况）

📘 解法二 · 官方 · 并查集

💡 每格自成一个集合，相邻陆地就 union 合并；扫完后"根是自己"的陆地格每岛恰有一个——数代表格就是岛数。

class Solution:
    def numIslands(self, grid):
        m, n = len(grid), len(grid[0])
        parent = list(range(m * n))      # 每格自成集合: 根先指向自己
        def find(x):                     # 找根, 顺带路径压缩
            while parent[x] != x:
                parent[x] = parent[parent[x]]   # 压缩: 先挂到爷爷
                x = parent[x]
            return x
        def union(a, b):                 # 合并两格所在的集合
            ra, rb = find(a), find(b)
            if ra != rb: parent[ra] = rb   # 根不同 → 老根认新根, 全族换旗
        for i in range(m):               # 扫描网格, 只盯陆地
            for j in range(n):
                if grid[i][j] == 1:
                    if i + 1 < m and grid[i+1][j] == 1:   # 下方是陆地 → union
                        union(i * n + j, (i + 1) * n + j)
                    if j + 1 < n and grid[i][j+1] == 1:   # 右方是陆地 → union
                        union(i * n + j, i * n + j + 1)
        return sum(1 for i in range(m) for j in range(n)
                   if grid[i][j] == 1 and find(i * n + j) == i * n + j)

P051 · LC994 腐烂的橘子 中等

解法: 多源 BFS，按分钟扩散

💡 多源 BFS：所有烂橘子第 0 分钟一起入队，一层 = 一分钟；出循环后 fresh 还有剩就是 -1。

from collections import deque
class Solution:
    def orangesRotting(self, grid):
        m, n = len(grid), len(grid[0])
        q = deque()                      # 队列: 存烂橘子的坐标
        fresh = 0                        # 新鲜橘子计数
        for i in range(m):               # 第一遍: 烂橘子全部入队
            for j in range(n):
                if grid[i][j] == 2:
                    q.append((i, j))
                elif grid[i][j] == 1:
                    fresh += 1
        minute = 0
        while q and fresh:               # 还有烂橘子且还有新鲜的才继续
            minute += 1                  # 新的一分钟
            for _ in range(len(q)):      # 本分钟: 队里所有烂橘子同时扩散
                i, j = q.popleft()
                for di, dj in ((1,0),(-1,0),(0,1),(0,-1)):
                    ni, nj = i + di, j + dj
                    if 0 <= ni < m and 0 <= nj < n and grid[ni][nj] == 1:
                        grid[ni][nj] = 2  # 被传染
                        fresh -= 1
                        q.append((ni, nj))
        return minute if fresh == 0 else -1

时间 O(mn)（每格最多入队一次）　·　空间 O(mn)（队列）

📘 解法二 · 官方 · 逐分钟模拟(不用队列)

💡 不用队列：每分钟整格重扫一遍，四邻有上一轮烂橘子的新鲜橘子记入 now 名单，本轮扫完才统一变烂；某轮零新增即停，收尾 fresh>0 则 -1。

# 解法二:力扣官方题解 方法二 逐分钟模拟(不用队列)
class Solution:
    def orangesRotting(self, grid):
        m, n = len(grid), len(grid[0])
        fresh = sum(row.count(1) for row in grid)
        minute = 0
        while fresh:                         # 还有新鲜橘子 → 再模拟一分钟
            minute += 1
            now = []                         # 本轮将烂名单: 只记账, 暂不改格
            for i in range(m):
                for j in range(n):
                    if grid[i][j] != 1:      # 只关心新鲜橘子
                        continue
                    for x, y in ((i+1,j),(i-1,j),(i,j+1),(i,j-1)):
                        if 0 <= x < m and 0 <= y < n and grid[x][y] == 2:
                            now.append((i, j))   # 四邻有上一轮的烂橘子
                            break
            if not now:                      # 本轮零新增 → 之后也烂不动了
                break
            for i, j in now:                 # 本轮扫描结束后, 统一腐烂!
                grid[i][j] = 2
                fresh -= 1
        return minute if fresh == 0 else -1

时间 O(mn·t)（t = 分钟数，每轮整格重扫一遍；BFS 版为 O(mn)）　·　空间 O(mn)（本轮名单 now）

P052 · LC207 课程表 中等

解法: 拓扑排序（Kahn 入度法）

💡 入度 = 还差几门先修课；入度 0 就上，上了就给后续课 −1；上不完必有环。

class Solution:
    def canFinish(self, numCourses, prerequisites):
        graph = [[] for _ in range(numCourses)]   # 邻接表: 修完 c 能解锁的课
        indeg = [0] * numCourses                  # 入度: 还差几门先修课
        for a, b in prerequisites:
            graph[b].append(a)                    # 箭头 b → a
            indeg[a] += 1                         # a 又多了一门先修
        q = [c for c in range(numCourses) if indeg[c] == 0]  # 入度 0 的直接能上
        done = 0
        while q:
            c = q.pop()                           # 取一门能上的课
            done += 1                             # 修完它
            for nxt in graph[c]:                  # 它解锁的课
                indeg[nxt] -= 1                   # 少了一门先修
                if indeg[nxt] == 0:               # 门槛全清 → 可以上了
                    q.append(nxt)
        return done == numCourses                 # 全上过 = 无环

时间 O(V + E)（课数 + 先修对数）　·　空间 O(V + E)（邻接表 + 队列）

📘 解法二 · 官方 · DFS 三色标记

💡 DFS 三色判环：u 能修完 ⇔ 它的先修都能修完；递归撞上"搜索中"＝先修成环。

class Solution:
    def canFinish(self, numCourses, prerequisites):
        graph = [[] for _ in range(numCourses)]   # graph[a]: a 的先修清单
        for a, b in prerequisites:
            graph[a].append(b)                    # 箭头 a → b: 修 a 前先修完 b
        color = [0] * numCourses                  # 0=未搜 1=搜索中 2=完成
        def dfs(u):                               # 证明: u 能不能修完
            color[u] = 1                          # 踩进 u → 标"搜索中"
            for v in graph[u]:                    # 逐门检查 u 的先修
                if color[v] == 1:                 # 撞上"搜索中" → 绕回自己: 有环!
                    return False
                if color[v] == 0 and not dfs(v):  # 只有未搜的先修才需要证明
                    return False                  # 有先修失败 → u 也修不完
            color[u] = 2                          # 先修全部证明完 → u 完成
            return True
        for u in range(numCourses):               # 从每门未搜的课出发证明
            if color[u] == 0 and not dfs(u):
                return False
        return True

时间 O(V + E)（每门课进出栈一次、每条边查一次）　·　空间 O(V + E)（邻接表 + 递归栈）

P053 · LC208 实现 Trie (前缀树) 中等

解法: 字典树：逐字符挂节点

💡 查单词 = 沿树走到头，再看终点是不是词尾（end）；查前缀 = 走到头就行。公共前缀共享一条路径——这就是前缀树。

class Trie:
    def __init__(self):
        self.son, self.end = {}, False   # 儿子表: 字符→子节点 / 词尾标记
    def insert(self, word):              # 逐字符沿树走, 缺就挂新节点
        cur = self
        for ch in word:
            cur = cur.son.setdefault(ch, Trie())
        cur.end = True                   # 走到头: 打上"词尾"记号
    def search(self, word):              # 查完整单词
        cur = self
        for ch in word:
            if ch not in cur.son: return False   # 走断了: 不存在
            cur = cur.son[ch]
        return cur.end                   # 恰好停在词尾才算数
    def startsWith(self, prefix):        # 查前缀
        cur = self
        for ch in prefix:
            if ch not in cur.son: return False
            cur = cur.son[ch]
        return True                      # 能走到头就是前缀

class Solution:                          # 校验驱动: 模拟评测器按操作序列调用
    def run(self, ops, args):
        t, out = None, []
        for op, arg in zip(ops, args):
            if op == 'Trie': t = Trie(); out.append(None)
            else: out.append(getattr(t, op)(arg[0]))
        return out

P054 · LC46 全排列 中等

解法: used 标记 + 回溯

💡 每层从左到右试每个没用过的数：选上 → 递归 → 撤销。used 数组负责"别回头查重"，path 长满 n 个就是答案。

class Solution:
    def permute(self, nums):
        n = len(nums)
        used = [False] * n            # used[i]: nums[i] 是否已进 path
        path, ans = [], []

        def dfs():                    # 本层职责: 给 path 挑下一个数
            if len(path) == n:        # 凑满 n 个 → 一个完整排列
                ans.append(path[:])   # 复制一份收进答案
                return
            for i in range(n):        # 每一层都从头试每个数
                if used[i]:           # 已被 path 用着 → 跳过
                    continue
                used[i] = True        # 做选择: 标记 + 进 path
                path.append(nums[i])
                dfs()                 # 递归挑下一个
                path.pop()            # 撤销选择(回溯)
                used[i] = False

        dfs()
        return ans

class Solution:

P057 · LC39 组合总和 中等

解法: 可重复选取 + 剪枝回溯

💡 两个动作走天下：再选一次当前数（i 不动），或者跳过它（i+1）。left 减到 0 收答案，减到负数立刻剪枝。

class Solution:
    def combinationSum(self, candidates, target):
        ans, path = [], []

        def dfs(i, left):              # 从 candidates[i] 开始挑, 还差 left
            if left == 0:              # 一分不差 → 找到一组
                ans.append(path[:])
                return
            if i == len(candidates) or left < 0:   # 没数可挑 / 超了 → 剪枝
                return
            path.append(candidates[i]) # 选 candidates[i]
            dfs(i, left - candidates[i])   # i 不动: 同一个数还能再选
            path.pop()                 # 撤销
            dfs(i + 1, left)           # 跳过它, 试下一个数

        return ans

P058 · LC22 括号生成 中等

解法: 回溯：左括号有余量就放，右括号多于左就能收

💡 回溯就是"每个位置都按规则试一遍，试完撤销"：left < n 就放 (，right < left 就放 )，凑满 2n 收答案——合法组合一个不漏。

class Solution:
    def generateParenthesis(self, n):
        ans, path = [], []

        def dfs(left, right):        # 已放 left 个 '(' 和 right 个 ')'
            if len(path) == 2 * n:   # 2n 个字符凑齐 → 这条路合法, 收答案
                ans.append(''.join(path))
                return
            if left < n:             # '(' 还有余量 → 可以放 '('
                path.append('(')
                dfs(left + 1, right)
                path.pop()           # 撤销, 回到岔路口
            if right < left:         # ')' 不比 '(' 多 → 可以收口
                path.append(')')
                dfs(left, right + 1)
                path.pop()           # 撤销, 回到岔路口

        dfs(0, 0)
        return ans

时间 O(4^n / √n)（卡特兰数个合法串，每个 O(n) 拼接）　·　空间 O(n)（递归栈 + path，不计返回值）

📘 解法二 · 官方 · 按长度 DP

💡 dp[i] = Σ_p dp[p] × dp[i−1−p] 再包一层 (a)b：第一对括号把串切成"内 a 外 b"两段，分解唯一所以不重，枚举穷尽所以不漏。

class Solution:
    def generateParenthesis(self, n):
        dp = [[] for _ in range(n + 1)]     # dp[i]: i 对括号的所有组合
        dp[0] = ['']                        # 地基: 0 对 = 空串
        for i in range(1, n + 1):           # 从 1 对凑到 n 对
            for p in range(i):              # 第一对括号里包 p 对
                for a in dp[p]:             # 括号内的部分逐个试
                    for b in dp[i - 1 - p]: # 括号后的部分逐个试
                        dp[i].append('(' + a + ')' + b)
        return dp[n]

P059 · LC79 单词搜索 中等

解法: 网格四方向回溯 + 现场标记

💡 走过的格子立刻盖章 #，四方向递归；返回前必须擦章恢复现场——让每次尝试都从"干净的棋盘"出发。

class Solution:
    def exist(self, board, word):
        m, n = len(board), len(board[0])
        def dfs(i, j, k):
            if k == len(word):          # 单词全部匹配完
                return True
            if i < 0 or i >= m or j < 0 or j >= n or board[i][j] != word[k]:
                return False            # 出界或字符对不上
            board[i][j] = '#'           # 现场标记: 盖章防重踩
            ok = (dfs(i + 1, j, k + 1) or dfs(i - 1, j, k + 1) or
                  dfs(i, j + 1, k + 1) or dfs(i, j - 1, k + 1))
            board[i][j] = word[k]       # 回溯: 擦章恢复现场
            return ok
        for i in range(m):
            for j in range(n):
                if dfs(i, j, 0):        # 每个格子都试试当起点
                    return True
        return False

P060 · LC131 分割回文串 中等

解法: 枚举切割点 + 回文判断回溯

💡 每层只决定"下一刀切到哪"：枚举 end → isPal 双指针验货 → 切下、递归、撤销。start 走到 len(s) 就收一份答案。

class Solution:
    def partition(self, s):
        ans, path = [], []
        def isPal(lo, hi):              # 双指针: s[lo..hi] 是回文吗
            while lo < hi:
                if s[lo] != s[hi]:
                    return False
                lo += 1
                hi -= 1
            return True
        def dfs(start):                 # 还没切的部分从 start 开始
            if start == len(s):         # 切到头, 收集一份
                ans.append(path[:])
                return
            for end in range(start, len(s)):   # 枚举这一段切到哪
                if isPal(start, end):          # 是回文才要
                    path.append(s[start:end + 1])
                    dfs(end + 1)               # 接着切后面
                    path.pop()                 # 撤销
        dfs(0)
        return ans

时间 O(n·2ⁿ)（最坏：每个前缀都是回文）　·　空间 O(n)（递归栈 + path，不计返回值）

📘 解法二 · 官方 · 回文预处理表

💡 先交 O(n²) 的"表钱"把所有子串是否回文一次算清，回溯验货从双指针 O(n) 变成查表 O(1)——空间换时间，适合同一串反复查询。

class Solution:
    def partition(self, s):
        n = len(s)
        isPal = [[False] * n for _ in range(n)]   # isPal[i][j]: s[i..j] 是回文吗
        for i in range(n - 1, -1, -1):            # i 倒着算: 内层区间先就绪
            for j in range(i, n):
                isPal[i][j] = s[i] == s[j] and (j - i < 2 or isPal[i + 1][j - 1])
        ans, path = [], []
        def dfs(start):                   # 回溯骨架与主解法一致
            if start == n:
                ans.append(path[:])
                return
            for end in range(start, n):   # 枚举这一段切到哪
                if isPal[start][end]:     # O(1) 查表, 不再双指针
                    path.append(s[start:end + 1])
                    dfs(end + 1)
                    path.pop()
        dfs(0)
        return ans

时间 O(n² + n·2ⁿ)（建表 O(n²) + 回溯 O(n·2ⁿ)）　·　空间 O(n²)（isPal 整张表；回溯栈另计 O(n)）

P061 · LC51 N 皇后 困难

解法: 逐行放置 + 列/对角线集合剪枝

💡 逐行放皇后（行冲突被结构消灭），列和对角线用三个集合记账：同一条主对角线 r−c 是定值、副对角线 r+c 是定值——O(1) 就知道一格安不安全。

class Solution:
    def solveNQueens(self, n):
        ans = []
        grid = [['.'] * n for _ in range(n)]
        col, d1, d2 = set(), set(), set()   # 列 / 主对角线(r-c) / 副对角线(r+c)
        def dfs(r):                  # 逐行放: 本行试每一列
            if r == n:               # n 行都放好 → 找到一个解
                ans.append([''.join(row) for row in grid])
                return
            for c in range(n):
                if c in col or (r - c) in d1 or (r + c) in d2:
                    continue         # 被攻击 → 跳过
                col.add(c); d1.add(r - c); d2.add(r + c)
                grid[r][c] = 'Q'     # 放置
                dfs(r + 1)           # 下一行
                grid[r][c] = '.'     # 撤销
                col.discard(c); d1.discard(r - c); d2.discard(r + c)
        dfs(0)
        return ans

P063 · LC74 搜索二维矩阵 中等

解法: 拉直成一维数组二分

💡 行末 < 下一行行首 ⇒ 拉直即有序：把 m×n 矩阵当长度 m·n 的有序数组二分，mid//n 是行、mid%n 是列。

class Solution:

💡 两次二分各管一维：先在首列二分锁定「最后一个行首 ≤ target 的行」，再在这行里二分找 target——O(log m) + O(log n)。

                return True
            if matrix[r][mid] < target:
                lo = mid + 1
            else:
                hi = mid - 1
        return False

💡 把两个边界翻译成同一个问题「第一个 ≥ x 的下标」：第一轮 x = target，第二轮 x = target + 1 再退一格——一套二分用两次。

class Solution:

P067 · LC4 寻找两个正序数组的中位数 困难

解法: 第 k 小：每次淘汰 k/2 个

💡 找第 k 小不必合并：两边各看第 k/2 个，较小的那一批前 k/2 个绝不可能是第 k 名——整队淘汰，k 每轮砍半，log 轮见分晓。

class Solution:
    def findMedianSortedArrays(self, nums1, nums2):
        def kth(a, b, k):                 # 合并后第 k 小(k 从 1 起)
            if len(a) > len(b):           # 让 a 恒为较短的那个
                return kth(b, a, k)
            if not a:                     # a 空了: 答案就是 b 的第 k 个
                return b[k - 1]
            if k == 1:                    # 两边都非空: 小者即第 1 小
                return min(a[0], b[0])
            i = min(k // 2, len(a))       # a 派第 i 个应战
            j = min(k // 2, len(b))       # b 派第 j 个应战
            if a[i - 1] <= b[j - 1]:      # a 的第 i 个不大于 b 的第 j 个
                return kth(a[i:], b, k - i)   # a 前 i 个挤不进前 k 名, 淘汰
            return kth(a, b[j:], k - j)       # 否则淘汰 b 的前 j 个
        total = len(nums1) + len(nums2)
        if total % 2:                     # 奇数: 中位数 = 正中那一个
            return kth(nums1, nums2, total // 2 + 1)
        return (kth(nums1, nums2, total // 2) +      # 偶数: 中间两个取平均
                kth(nums1, nums2, total // 2 + 1)) / 2

P069 · LC155 最小栈 中等

解法: 辅助栈同步记录当前最小

💡 主栈管进出，辅助栈管"历届冠军"：只有不比当前最小大的值才有资格进辅助栈；弹掉最小值时两个栈一起弹——getMin 永远只是读一下栈顶。

class MinStack:
    def __init__(self):
        self.st = []                 # 主栈: 老老实实存每个值
        self.mi = []                 # 辅助栈: 栈顶永远是当前最小
    def push(self, x):
        self.st.append(x)            # 主栈照常进
        if not self.mi or x <= self.mi[-1]:
            self.mi.append(x)        # 不比最小大, 辅助栈也进
    def pop(self):
        x = self.st.pop()            # 主栈弹谁
        if x == self.mi[-1]:
            self.mi.pop()            # 弹的正是最小值, 辅助栈跟着弹
    def top(self):
        return self.st[-1]
    def getMin(self):
        return self.mi[-1]           # O(1) 读栈顶即是答案

class Solution:                      # 校验驱动: 模拟评测器按序调用
    def run(self, ops, args):
        s, out = None, []
        for op, arg in zip(ops, args):
            if op == 'MinStack': s = MinStack(); out.append(None)
            elif op == 'push': s.push(arg[0]); out.append(None)
            elif op == 'pop': s.pop(); out.append(None)
            else: out.append(getattr(s, op)())
        return out

P072 · LC84 柱状图中最大的矩形 困难

解法: 单调递增栈 + 哨兵收尾

💡 单调递增栈 + 哨兵：柱子只比栈顶高就进栈排队；一来根更矮的，栈顶的左右边界就齐了——高 = 它自己，宽 = i − 新栈顶 − 1，弹一根结一笔。哨兵 0 保证最后一根也不漏。

class Solution:
    def largestRectangleArea(self, heights):
        h = heights + [0]             # 哨兵: 末尾垫个 0, 逼栈里全部结算
        st, best = [], 0              # 单调递增栈: 存下标
        for i, x in enumerate(h):
            while st and h[st[-1]] >= x:
                ht = h[st.pop()]      # 栈顶右边界到了, 出栈结算
                left = st[-1] if st else -1   # 左边界 = 弹完后的新栈顶
                best = max(best, ht * (i - left - 1))  # 宽 × 高
            st.append(i)              # 自己进栈
        return best

时间 O(n)（每根柱子至多进栈/出栈各一次）　·　空间 O(n)（栈）

P073 · LC215 数组中的第K个最大元素 中等

解法: 快速选择（partition 缩小范围）

💡 第 k 大 = 升序下标 n − k。每趟 partition 让 pivot 归位：p == k 直接收工；p < k 只进右段，p > k 只进左段——每趟平均砍一半，平均 O(n)。

class Solution:
    def findKthLargest(self, nums, k):
        k = len(nums) - k             # 第 k 大 = 升序下标 n-k
        lo, hi = 0, len(nums) - 1
        while True:
            p = self.partition(nums, lo, hi)   # 分一趟, pivot 归位到 p
            if p == k:
                return nums[p]        # 正好落在目标下标
            elif p < k:
                lo = p + 1            # 答案在右段
            else:
                hi = p - 1            # 答案在左段
    def partition(self, a, lo, hi):
        pivot = a[hi]                 # 拿末位当基准
        i = lo                        # i: 下一个"小于 pivot"的坑位
        for j in range(lo, hi):
            if a[j] < pivot:          # 比 pivot 小 -> 换到左边
                a[i], a[j] = a[j], a[i]
                i += 1
        a[i], a[hi] = a[hi], a[i]     # pivot 归位
        return i

平均时间 O(n)（每趟期望砍半）　·　最坏 O(n²)　·　空间 O(1)（原地 partition，只递归/循环一段）

📘 解法二 · 官方 · 大小为 k 的小顶堆

💡 只装 k 个元素的小顶堆：堆里始终是当前最大的 k 个，堆顶 = 第 k 大的门槛；扫完，堆顶就是答案。

import heapq                          # 官方解法本色: 直接用现成的小顶堆

class Solution:
    def findKthLargest(self, nums, k):
        heap = []                           # 小顶堆: 只装"当前最大的 k 个"
        for x in nums:                      # 逐个过数组
            if len(heap) < k:               # 堆未满 → 先装满
                heapq.heappush(heap, x)
            elif x > heap[0]:               # 比堆顶(门槛)大 → 有资格进前 k
                heapq.heapreplace(heap, x)  # 踢掉堆顶, 自己顶上
        return heap[0]                      # 堆里最小的 = 第 k 大

时间 O(n log k)（每个元素至多一进一出堆，各 O(log k)）　·　空间 O(k)（堆）

P074 · LC347 前 K 个高频元素 中等

解法: 哈希计数 + 桶排序

💡 先数后装桶：桶的下标就是出现次数，天然有序——从最高的桶往低处收 k 个，比堆排序还省事，整体 O(n)。

class Solution:
    def topKFrequent(self, nums, k):
        cnt = {}                                   # ① 数字 -> 出现次数
        for x in nums:
            cnt[x] = cnt.get(x, 0) + 1
        buckets = [[] for _ in range(len(nums) + 1)]   # ② 桶: 下标 = 出现次数
        for x, c in cnt.items():                   # 每个数丢进自己频率的桶
            buckets[c].append(x)
        ans = []
        for c in range(len(buckets) - 1, 0, -1):   # ③ 频率从高到低扫桶
            for x in buckets[c]:
                if len(ans) < k:                   # 还没收满 k 个
                    ans.append(x)                  # 才收进答案
        return ans                                 # 从高到低, 收满为止

时间 O(n)（数一遍 + 装桶 + 扫桶）　·　空间 O(n)（哈希表 + 桶）

P075 · LC295 数据流的中位数 困难

解法: 对顶堆：大顶堆 + 小顶堆

💡 两堆对顶分天下：lo 管小的一半、hi 管大的一半，随时保证 |lo|−|hi| ≤ 1——中位数要么是 lo 顶，要么是两顶平均，一眼可取。

import heapq

class MedianFinder:
    def __init__(self):
        self.lo = []                 # 大顶堆(存相反数): 较小的一半
        self.hi = []                 # 小顶堆: 较大的一半
    def addNum(self, num):
        heapq.heappush(self.lo, -num)                  # ① 先无脑丢进 lo
        heapq.heappush(self.hi, -heapq.heappop(self.lo))   # ② lo 最大的让给 hi
        if len(self.hi) > len(self.lo):                # ③ hi 多了一个
            heapq.heappush(self.lo, -heapq.heappop(self.hi))   # 还一个给 lo
    def findMedian(self):
        if len(self.lo) > len(self.hi):                # 奇数个: lo 多一个
            return -self.lo[0]                         # lo 顶就是中位数
        return (-self.lo[0] + self.hi[0]) / 2          # 偶数个: 两堆顶平均

class Solution:                      # 校验驱动: 模拟评测器按序调用
    def run(self, ops, args):
        mf, out = None, []
        for op, arg in zip(ops, args):
            if op == 'MedianFinder': mf = MedianFinder(); out.append(None)
            elif op == 'addNum': mf.addNum(arg[0]); out.append(None)
            else: out.append(mf.findMedian())
        return out

addNum 时间 O(log n)　·　findMedian 时间 O(1)　·　空间 O(n)（两个堆分摊所有数）

P077 · LC55 跳跃游戏 中等

解法: 维护最远可达 far

💡 贪心只记一个最远可达 far：每扫过一格就把 far 往远处推（max(far, i+nums[i])）；哪天 i 越过了 far，中间必有跳不过去的沟——直接判负。

class Solution:

            far = max(far, i + step)   # 站上这格, 把最远可达往外推
        return True                    # 扫完没卡死 → 终点必可达

P078 · LC45 跳跃游戏 II 中等

解法: 层序贪心：当前层尽头/下一层尽头

💡 把跳跃当 BFS 分层：farthest 记下一层最远，扫到 cur_end 就 jumps+1 并把 cur_end 推到 farthest——层数即最少跳数，一趟 O(n)。

class Solution:
    def jump(self, nums):
        jumps = 0                 # 已经跳了几步
        cur_end = 0               # 当前层的最右边界
        farthest = 0              # 扫描中发现的下一层最远
        for i in range(len(nums) - 1):     # 最后一格不用扫
            farthest = max(farthest, i + nums[i])   # 谁更远?
            if i == cur_end:      # 走到当前层尽头
                jumps += 1        # 被迫再跳一步
                cur_end = farthest  # 边界推进到下一层
        return jumps

时间 O(n)（每格看一次）　·　空间 O(1)（只有三个变量）

P079 · LC763 划分字母区间 中等

class Solution:
    def partitionLabels(self, s):
        last = {}                     # 字母 -> 最后出现的下标
        for i, ch in enumerate(s):    # 第 1 趟: 建表
            last[ch] = i
        parts = []                    # 每段的长度

            if i == end:              # 走到窗口尽头 -> 切!
                parts.append(end - start + 1)
                start = end + 1
        return parts

        return b                   # f(n)

P081 · LC118 杨辉三角 简单

解法: 逐行构造，两端为 1

class Solution:

        return tri

P082 · LC198 打家劫舍 中等

解法: 滚动 dp：偷或不偷相邻两家

💡 每家二选一：不偷继承 prev1，偷则 prev2 + num，取大滚向前——f(i) 只依赖前两个 f，两个滚动变量走完全程，O(n) 时间 O(1) 空间。

class Solution:

            prev1 = cur
        return prev1               # 最后一家为止的最优

P083 · LC279 完全平方数 中等

解法: 完全背包：f(i)=min(f(i-j²))+1

💡 f[i] = min(f[i−j²]) + 1：想凑出 i，先把某块平方数 j² 拿走当"最后一块"，剩下 i−j² 用它自己的最优解，再加这一块。从小往大填表，每格都站在已算好的格子上。

class Solution:
    def numSquares(self, n):
        f = [0] + [float('inf')] * n   # f[i]: 凑出 i 最少要几个平方数
        for i in range(1, n + 1):      # 从小到大, 依次凑出 1..n
            j = 1
            while j * j <= i:          # 枚举不超过 i 的平方数 j*j
                f[i] = min(f[i], f[i - j*j] + 1)   # 拆出 j*j, 剩下 i-j*j 的最优解+1
                j += 1
        return f[n]

时间 O(n·√n)　·　空间 O(n)（f 表）

P084 · LC322 零钱兑换 中等

解法: 完全背包求最少硬币数

💡 f[x] = min(f[x−c]) + 1：把每种硬币轮流当"最后一枚"，剩下的钱用最优解，再加这一枚。全表从 ∞ 起步，谁也救不回来的格子最后返回 −1。

class Solution:
    def coinChange(self, coins, amount):
        f = [0] + [float('inf')] * amount   # f[x]: 凑出 x 最少要几枚硬币
        for x in range(1, amount + 1):      # 从 1 元一路凑到 amount 元
            for c in coins:                 # 每种硬币都试当"最后一枚"
                if c <= x and f[x - c] + 1 < f[x]:
                    f[x] = f[x - c] + 1     # 用这枚收尾更省
        return f[amount] if f[amount] < float('inf') else -1

时间 O(amount × 硬币种数)　·　空间 O(amount)（f 表）

📘 解法二 · 官方 · 记忆化搜索

💡 dp(x) = min(dp(x−c)) + 1，自顶向下要答案、算完就记进 memo 表——和自底向上填表是同一个递推的两个方向。

class Solution:
    def coinChange(self, coins, amount):
        memo = [None] * (amount + 1)     # memo[x]: 凑 x 最少几枚; None=还没算过
        memo[0] = 0                      # 地基: 0 元用 0 枚

        def dp(x):                       # 自顶向下: 先要大问题的答案
            if x < 0:                    # 硬币塞爆了 → 此路不通
                return -1
            if memo[x] is not None:      # 查表命中 → 直接返回, 不重算!
                return memo[x]
            best = amount + 1            # 哨兵: 比任何答案都大
            for c in coins:              # 每种硬币轮流当"最后一枚"
                sub = dp(x - c)          # 递归问: 剩下 x−c 元最少几枚
                if sub != -1 and sub + 1 < best:
                    best = sub + 1
            memo[x] = -1 if best > amount else best   # 算完写表, 下次秒回
            return memo[x]

        return dp(amount)

时间 O(amount × 硬币种数)（每个金额至多真算一次）　·　空间 O(amount)（memo 表 + 递归栈）

P086 · LC300 最长递增子序列 中等

解法: O(n²) DP：以 i 结尾的最长上升

💡 dp[i] = 1 + max(dp[j])：只在"j 在 i 左边且 nums[j] < nums[i]"的 j 里挑最长的接上来；谁也不接就是 1。答案 = max(dp)，不一定是最后一个。

class Solution:
    def lengthOfLIS(self, nums):
        n = len(nums)
        dp = [1] * n                    # dp[i]: 以 nums[i] 结尾的 LIS 长度
        for i in range(1, n):           # 逐个确定"以 i 结尾"的答案
            for j in range(i):          # j: i 左边的接驳点候选
                if nums[j] < nums[i]:   # nums[i] 能接在 nums[j] 后面
                    dp[i] = max(dp[i], dp[j] + 1)
        return max(dp)                  # LIS 可能停在任何位置, 取全表最大

时间 O(n²)　·　空间 O(n)（dp 表）

📘 解法二 · 官方 · 贪心 + 二分

💡 tails[k] 永远记"长度 k+1 的递增子序列的最小结尾"：每个 x 二分找第一个 ≥ x 的位置——找到就替换（同长度结尾更小，潜力只增不减），比谁都大就追加（LIS 变长）。答案 = len(tails)。

class Solution:
    def lengthOfLIS(self, nums):
        tails = []                      # tails[k]: 长度 k+1 的递增子序列的最小结尾
        for x in nums:                  # 逐个接待新数
            lo, hi = 0, len(tails) - 1  # 二分区间 [lo, hi]
            while lo <= hi:             # 找第一个 >= x 的位置
                mid = (lo + hi) // 2
                if tails[mid] < x:      # 中点结尾比 x 小 → 第一名在右半
                    lo = mid + 1
                else:                   # tails[mid] >= x → 中点是候选, 缩左半
                    hi = mid - 1
            if lo == len(tails):        # x 比所有结尾都大
                tails.append(x)         # 追加: 最长长度 +1
            else:                       # lo 就是第一个 >= x 的位置
                tails[lo] = x           # 替换: 同长度结尾压得更小
        return len(tails)               # tails 长度 = LIS 长度

P087 · LC152 乘积最大子数组 中等

解法: 同时维护最大积和最小积

class Solution:

        curMax = curMin = ans = nums[0]   # 以当前元素结尾的最大/最小积 & 全局答案
        for x in nums[1:]:                # 逐个把 x 接到子数组末尾

            curMin = min(x, curMin * x)   # 同理维护最惨的积

P088 · LC416 分割等和子集 中等

解法: 0-1 背包：能否凑出 sum/2

💡 target = 总和一半就是背包容量：dp[j] = dp[j] 或 dp[j−x]，j 从大到小倒序更新——倒序保证每个数只用一次。

class Solution:
    def canPartition(self, nums):
        total = sum(nums)
        if total % 2 == 1:                # 总和是奇数, 平分不了
            return False
        target = total // 2               # 目标: 凑出总和的一半
        dp = [False] * (target + 1)       # dp[j]: 能否从 nums 凑出和 j
        dp[0] = True                      # 什么都不选, 先凑出 0
        for x in nums:                    # 逐个考虑每个数
            for j in range(target, x - 1, -1):   # j 倒着扫, 防止 x 重复用
                if dp[j - x]:             # 凑出 j-x 的方案有了吗?
                    dp[j] = True          # 有: 加上 x 就凑出 j
            if dp[target]:                # 凑出 target 就提前收工
                return True
        return dp[target]

时间 O(n × target)　·　空间 O(target)（一维滚动 dp 表）

📘 解法二 · 教科书 · 二维 DP 表

💡 dp[i][j] = dp[i−1][j]（不选 x）或 dp[i−1][j−x]（选 x）——每格只看上一行、逐格填完整张表；一维倒序就是它的滚动压缩。

class Solution:
    def canPartition(self, nums):
        total = sum(nums)
        if total % 2 == 1:              # 总和是奇数, 平分不了
            return False
        target = total // 2
        n = len(nums)
        dp = [[False] * (target + 1) for _ in range(n + 1)]   # dp[i][j]: 前 i 个数能否凑出 j
        for i in range(n + 1):
            dp[i][0] = True             # 地基: 什么都不选, 和 0 总能凑出
        for i in range(1, n + 1):       # 逐行引入第 i 个数
            for j in range(1, target + 1):
                dp[i][j] = dp[i - 1][j]     # 不选 nums[i-1]: 正上方直接抄
                if j >= nums[i - 1] and dp[i - 1][j - nums[i - 1]]:
                    dp[i][j] = True         # 选 nums[i-1]: 左上能凑 j-x 就能凑 j
        return dp[n][target]

class Solution:

P091 · LC64 最小路径和 中等

解法: 网格 DP：上/左 取小

💡 dp[r][c] = min(dp[r−1][c], dp[r][c−1]) + grid[r][c]：前半程先便宜到上格或左格，再付这一格的过路费。

class Solution:
    def minPathSum(self, grid):

        dp = [[0] * n for _ in range(m)]    # dp[r][c]: 到 (r,c) 的最小路径和
        dp[0][0] = grid[0][0]               # 起点的最小和 = 自己的值

class Solution:

P093 · LC72 编辑距离 中等

解法: 二维 DP：增/删/改 取最小

💡 dp[i][j] = word1 前 i 个 → word2 前 j 个的最少步数：字符相同抄左上；否则 min(左上=改, 上=删, 左=增) + 1。

class Solution:
    def minDistance(self, word1, word2):
        m, n = len(word1), len(word2)
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(m + 1):      # 第 0 列: 删光
            dp[i][0] = i
        for j in range(n + 1):      # 第 0 行: 插入
            dp[0][j] = j

                    dp[i][j] = dp[i-1][j-1]  # 白拿左上
                else:               # 增删改取最小
                    dp[i][j] = 1 + min(
                        dp[i-1][j],     # 删
                        dp[i][j-1],     # 增
                        dp[i-1][j-1])   # 改

P094 · LC5 最长回文子串 中等

解法: 中心扩展：奇偶两种中心

💡 枚举每个中心（奇 + 偶两种），L、R 向两边扩到不能扩为止，用 r−l−1 量长度，破纪录就记下 —— O(n²) 但代码最短、最不容易写错。

class Solution:
    def longestPalindrome(self, s):
        n = len(s)
        best = ''
        for c in range(n):          # 每个位置当一次中心
            for l, r in [(c, c), (c, c+1)]: # 奇/偶中心
                while l >= 0 and r < n and s[l]==s[r]:
                    l -= 1          # 两侧相等, 左针左移
                    r += 1          # 右针右移
                if r - l - 1 > len(best): # 更长的回文
                    best = s[l + 1:r]   # 记下新答案
        return best

时间 O(n²)　·　空间 O(1)（只记最佳区间）

📘 解法二 · 官方 · 区间 DP

💡 dp[i][j] = 两端相等 且（长度 ≤3 或 里层 dp[i+1][j−1] 回文）——按长度从小到大填表，短串铺路、长串查表，边填边记最长。

class Solution:
    def longestPalindrome(self, s):
        n = len(s)
        if n < 2:                  # 空串/单字符本身就是答案
            return s
        dp = [[False] * n for _ in range(n)]   # dp[i][j]: s[i..j] 是否回文
        for i in range(n):         # 地基: 长度 1 全是回文
            dp[i][i] = True
        max_len, begin = 1, 0      # 最佳保底: 任意单字符
        for L in range(2, n + 1):  # 按子串长度从小到大
            for i in range(n - L + 1):   # 该长度下枚举左端点
                j = i + L - 1        # 右端点由 L 和 i 定死
                if s[i] != s[j]:     # 两端不等
                    dp[i][j] = False # 必不是回文
                else:                # 两端相等
                    dp[i][j] = j - i < 3 or dp[i + 1][j - 1]   # 长≤3 直接成立, 否则查里层
                if dp[i][j] and j - i + 1 > max_len:   # 破纪录才换(等长不换)
                    max_len, begin = j - i + 1, i
        return s[begin:begin + max_len]

时间 O(n²)（表上每格 O(1)）　·　空间 O(n²)（整张 dp 表）

class Solution:

P099 · LC287 寻找重复数 中等

解法: 下标当指针 → Floyd 判圈找入口

💡 把 i → nums[i] 当"下一站"：重复数 = 环入口。快慢指针圈内相遇后，一个回 0 同速走，再相遇即入口。

class Solution:
    def findDuplicate(self, nums):
        slow = fast = 0              # 都从下标 0 出发
        while True:                  # 快的每次跳两步
            slow = nums[slow]        # 慢的走一步
            fast = nums[nums[fast]]  # 快的走两步
            if slow == fast:         # 在圈里相遇
                break
        slow = 0                     # 慢的送回起点
        while slow != fast:          # 两个同速前进
            slow = nums[slow]
            fast = nums[fast]
        return slow                  # 再相遇点 = 圈入口 = 重复数

时间 O(n)（慢针最多走一圈）　·　空间 O(1)（不排序、不建表、不改数组）

📘 解法二 · 官方 · 二分答案 + 计数

💡 在值域 [1, n] 上二分答案：cnt(≤mid) > mid ⇔ 重复数 ≤ mid（鸽笼原理两个方向都成立），每数一遍数组就把区间砍半，缩到 lo == hi 即重复数。

class Solution:
    def findDuplicate(self, nums):
        lo, hi = 1, len(nums) - 1     # 在值域 1 ~ n 上二分(n = len-1), 不是下标!
        while lo < hi:
            mid = (lo + hi) // 2      # 猜一个中点
            cnt = 0
            for v in nums:            # 数一遍: 有多少个数 <= mid
                if v <= mid:
                    cnt += 1
            if cnt > mid:             # 鸽笼: cnt 个数挤 mid 种值必重
                hi = mid              # 重复数在 [lo, mid]
            else:                     # cnt <= mid: 左半住得下, 不必重
                lo = mid + 1          # 重复数在 [mid+1, hi]
        return lo                     # 区间缩成一点 = 重复数

P100 · LC289 生命游戏 中等

解法: 原位标记：二进制次位存下一代

💡 原地更新：用二进制第 2 位当草稿记下一代（1→3 活着、0→2 复活），数邻居 &1 只看旧状态，最后全体 >>=1 转正。

class Solution:
    def gameOfLife(self, board):
        m, n = len(board), len(board[0])
        for r in range(m):                     # 第一遍: 数邻居、打标记
            for c in range(n):
                live = 0                       # 8 邻居里的活细胞数
                for dr in (-1, 0, 1):
                    for dc in (-1, 0, 1):
                        if dr == 0 and dc == 0:
                            continue           # 跳过自己
                        if 0 <= r + dr < m and 0 <= c + dc < n:
                            live += board[r + dr][c + dc] & 1   # & 1: 只看旧状态
                if board[r][c] & 1:            # 自己现在是活的
                    if live == 2 or live == 3: # 活到下代: 邻居 2 或 3 个
                        board[r][c] |= 2       # 二号位打"下代活"标记
                elif live == 3:                # 自己是死的
                    board[r][c] |= 2           # 恰好 3 个活邻居 → 复活
        for r in range(m):                     # 第二遍: 草稿转正
            for c in range(n):
                board[r][c] >>= 1              # 右移一位, 新状态落位

时间 O(m·n)（每格数 8 个邻居）　·　空间 O(1)（高位当草稿，原地标记）

📘 解法二 · 官方 · 复制新板模拟

💡 复制一块新棋盘当只读底片：数邻居只看底片、下一代写进新板——物理隔离天然保住"同时更新"，代价是多 O(m·n) 空间。

class Solution:
    def gameOfLife(self, board):
        m, n = len(board), len(board[0])
        nxt = [row[:] for row in board]   # 复制一块新棋盘: 旧状态只读
        for r in range(m):                # 逐格扫描
            for c in range(n):
                live = 0                  # 8 邻居里的活细胞数
                for dr in (-1, 0, 1):
                    for dc in (-1, 0, 1):
                        if dr == 0 and dc == 0:
                            continue      # 跳过自己
                        if 0 <= r + dr < m and 0 <= c + dc < n:
                            live += nxt[r + dr][c + dc]   # 只读底片, 永不污染
                if nxt[r][c] == 1 and live in (2, 3):
                    board[r][c] = 1       # 活着且邻居 2/3 个 → 存活
                elif nxt[r][c] == 0 and live == 3:
                    board[r][c] = 1       # 死细胞恰好 3 个活邻居 → 复活
                else:
                    board[r][c] = 0       # 其余一律死
